# GameZone Rental PlayStation
## Deskripsi Proyek
Proyek ini adalah program konsol Java untuk praktikum pemrograman Java Dasar Universitas Muhammadiyah Tasikmalaya. Program berfungsi menghitung biaya penyewaan konsol PlayStation 4 dan PlayStation 5, lengkap dengan perhitungan diskon dan biaya minuman tambahan, serta dapat melakukan transaksi berulang.

## Fitur Program
1. Input nama pelanggan
2. Pilihan konsol PS4 (Rp 8.000 / jam) dan PS5 (Rp 12.000 / jam)
3. Perhitungan diskon 10% apabila durasi sewa minimal 3 jam
4. Opsi tambahan minuman seharga Rp 5.000
5. Menampilkan struk transaksi lengkap
6. Pilihan transaksi baru atau mengakhiri program

## Cara Menjalankan Program
1. Buka proyek pada Apache NetBeans IDE
2. Jalankan program dengan menekan tombol `F6`
3. Isi data sesuai petunjuk yang muncul di jendela output
4. Program akan menampilkan struk setelah semua data diinput
